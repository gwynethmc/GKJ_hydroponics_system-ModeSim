# GKJ Hydroponics System - ModeSim

This project cleans hydroponics sensor data, trains an AI forecaster, and compares
reactive and proactive control modes through a system simulation.

## Documentation checklist

This final simulation artifact includes the required documentation items:

- Python source code

- Configuration files (if applicable)
- Installation instructions

## Project files

All notebooks and data files are in
`hydroponicsystem_code/`.

| File | Purpose |
| --- | --- |
| `clean_hydroponicsdata.ipynb` | Cleans the raw sensor data, resamples it to one-minute intervals, interpolates numeric readings, and writes `clean_hydroponicsdata.csv`. |
| `train_AIForecaster.ipynb` | Trains the XGBoost forecaster from the cleaned CSV and writes `forecaster.pkl`. |
| `hydroponics_simulation.ipynb` | Loads the cleaned data, evaluates the forecaster, runs the scenario simulations, and generates the final warning visualizations. |
| `clean_hydroponicsdata.csv` | Prepared data used by the forecaster and simulation. |
| `forecaster.pkl` | Saved trained XGBoost model. It can be regenerated by running the training notebook. |
| `archive.zip` | Archived bundle of related dataset artifacts and supporting materials. |
| `temperature_boxplots.png` | Exploratory chart showing temperature-related trends. |
| `scenario1-visualization.png` | Sample output for Scenario 1. |
| `scenario2-visualization.png` | Sample output for Scenario 2. |
| `scenario3-visualization.png` | Sample output for Scenario 3. |

## Warning visualization summary

The simulation uses a 15-minute forecast horizon and monitors:

- pH
- water temperature
- DHT temperature
- water level

The warning panel classifies forecast states as:

| Status | Meaning |
| --- | --- |
| Green | No predicted threshold breach |
| Yellow | One predicted parameter breach |
| Red | Two predicted parameter breaches |
| Dark Red | Three predicted parameter breaches |

This is a proactive monitoring aid meant to highlight likely future stress conditions before they occur.

## Forecast warning visualization

In addition to the reactive/proactive scenario comparison, the simulation
notebook evaluates the AI forecast at `t + 15 minutes`:

- pH is within the safe range when it is between `5.5` and `6.5`.
- Water temperature is within the limit when it is at or below `24°C`.
- Water level is within the simulation's safe range when it is at or above `2`.

The warning panel classifies each forecast time step as:

| Status | Meaning |
| --- | --- |
| Green | No predicted threshold breach |
| Yellow | One predicted parameter breach |
| Red | Two predicted parameter breaches |
| Dark Red | Three predicted parameter breaches |

The notebook also logs the breached parameters and consecutive
out-of-bounds exposure duration. The visualization is a proactive aid: it
shows predicted risk 15 minutes ahead and should be confirmed against current
sensor readings before a physical system adjustment is made.

## Troubleshooting

### `FileNotFoundError` for the CSV

Make sure the notebook is running with `hydroponicsystem_code` as its working
directory and that `clean_hydroponicsdata.csv` exists there.

### The cleaning notebook cannot find the raw CSV

Use the bundled file at:

```text
hydroponicsystem_code/archive/IoTData --Raw--.csv
```

Update the raw-data path in `clean_hydroponicsdata.ipynb` to your local path,
then run the notebook again.

### XGBoost is missing

```powershell
python -m pip install xgboost
```

Restart the notebook kernel after installing it.

### Outputs or variables look stale

Restart the kernel and run all cells in order. Do not run only the final
simulation cell in a new kernel because it depends on variables created by the
earlier cells.

## Expected result

The final simulation displays results for:

- Baseline
- Scenario 1: pH drift
- Scenario 2: thermal stress
- Scenario 3: compound crisis

The output compares reactive and proactive modes using final yield,
yield improvement, and out-of-bounds duration. The forecaster evaluation also
reports RMSE and MAE for pH, water temperature, DHT temperature, and water
level. The warning visualization additionally shows the forecasted pH,
water temperature, water level, warning severity, and exposure log. The
scenario summary also reports the first warning level, the response taken,
and the number of alerts for both reactive and proactive control modes. The
response table distinguishes between a proactive reset triggered by the
`t + 15` forecast, a reactive reset applied after the simulated delay, and a
warning that is still waiting for a reactive reset.
